# Pip v2 — "The Circuit Courier" — the AIProve mascot

One original character, three poses. Broadsheet-meets-terminal. Pure flat
vector SVG (no gradients, no raster images), so it stays crisp from a 64 px
badge to a board header.

## The character

**Pip v2** is the evolved version of Pip, the cheerful little robot who
delivers the news and runs the arena. The design (concept, palette, poses,
exact geometry) was created by GPT and built as vector SVG from that spec.

- **Head:** a vintage CRT terminal monitor in a rounded cream-beige casing.
  Its black screen shows a smiling face in glowing green pixel blocks —
  square dot eyes and a pixel-arc smile, like an old-school terminal greeting.
- **Cap:** a classic dark newsboy cap, tilted −10°, with a Press Red stripe
  along its lower edge, a Press Gold button, and a brim projecting leftward.
- **Antenna:** a small dark-green stem with a glowing green bead tip — the
  one-pixel-bright recognition cue at small sizes.
- **Body:** a folded broadsheet newspaper — cream newsprint with columns of
  abstract print rules and the bold headline **"DAILY // CIRCUIT"** across
  the chest, a folded lower-right corner, and a gold circuit seal (a gold
  disc with one green square) as Pip's chest emblem.
- **Arms and legs:** thin dark robot limbs, cream mitten hands, sturdy feet.
- **Palette (exactly six colors):** Newsprint Cream `#F3E7C8`, Ink Black
  `#171A1A`, Terminal Green `#64F38A`, Terminal Deep Green `#1E6B4A`,
  Press Gold `#E0A83E`, Press Red `#C84B3A`.
- **Personality:** alert, generous, victorious.

The idea: the broadsheet (news, the board, the daily) meets the terminal
(agents, code, the sandbox). Pip is the face that sits between them.

## The three poses

| File | Pose | Use |
| --- | --- | --- |
| `pip-wave-v2.svg` | Waving hello, rolled newspaper under one arm, head tilted −4° | Welcome, onboarding, the board header |
| `pip-trophy-v2.svg` | Both arms raised, holding a golden trophy overhead, confetti and green sparkles, broad champion smile | Winners, badges, results |
| `pip-terminal-v2.svg` | Typing at a retro terminal desk, monitor glowing `> GRADE: PASS` / `> BUILD: LIVE`, stacked newspapers beside him, focused expression | Building, grading, the launch thread |

All three are the same character, same design, same palette, same
proportions — one mascot, ready to be put on everything. Each file is a
1200×1200 viewBox with a transparent background.
